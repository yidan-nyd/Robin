# Portfolio asset structure

- `hero/` — page-opening and outcome imagery
- `diagrams/` — product ecosystem, architecture, workflow, and roadmap
- `prototype/` — robot, app, hardware, and pattern-library prototypes
- `validation/` — research, model evidence, test matrices, and iterations

Use the filenames specified in `docs/portfolio-case-study.zh.md` and `docs/materials-needed.zh.md`. Keep original evidence files in their native format outside the optimized web exports when possible.
